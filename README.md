# JMAXPET 内部操作系统 — 一期 Demo

给客户看产品形态的**可点击前端 demo**：Next.js 15 App Router + TypeScript + Tailwind v4 + shadcn/ui（Base UI）+ zustand。
没有后端、数据库、登录鉴权；所有数据来自 `src/data/*.ts` 的 seed，所有"保存"只改内存，**刷新页面即回到 seed**。

一期原则：**Case 是唯一信息源，8 个角色各看各的，workflow 每一步有人、有日期、有状态、有附件可追。**
财务只读、司机继续用网页手机版、短信只在紧急事件时发给负责人；记账 / 多币种 / AI 录单 / 司机 app 属于二期。

## 跑起来

```bash
pnpm install        # 或 npm install
pnpm dev            # http://localhost:3000
```

首页是登录选择页，点任一账号即登录（无密码）。短信默认为模拟发送；要真实发送，在 `.env.local` 里配置：

```
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
TWILIO_FROM=+1xxxxxxxxxx
```

## 8 个角色

| 账号 | 角色 | 登录后看到 |
|---|---|---|
| Rita | 操作部管理员 / 老板 | 全部 Case、全部页面、账号与权限；紧急事件短信对象 |
| Amy / Ben | 销售 | 只有「接单信息表」：新单录入 + 自己的历史接单（按实际出发月份分组） |
| 小林 / 小周 | 操作员 — 前期文件 | 只看自己负责的 Case；录单、文件 Timeline、司机安排、提前通知订舱 |
| Teddy | 托运订舱 | 只看转给自己的托运 Case；只编辑 航班与订舱（航线速查填入 / 手动录入 / 确认 AWB / 标记航变） |
| Vivian | 随机订舱 | 只看随机 Case；找随机人、加宠物位置、进度备注（2 天未更新提醒） |
| 小张（香港 / 中国大陆）/ 小何（其他国家） | 操作员 — 后段 | 按入境地区划分；待办里看出发 / 落地 / 入境口岸，点「已到家」自动归档 |
| 阿财 | 财务（只读） | 看全部 Case 收款状态与额外费用；待办 = 需收款（自动生成） |
| 老王（YYZ）/ 老李（YVR） | 司机 | 手机端：今日任务 / 紧急变动 / 日历 / 历史任务 |

**切换账号**：顶栏右侧下拉一键切换，保留当前内存数据（演示"A 做了操作，B 能看到"）。**当前日期**：顶栏可拨到任意一天，触发 48h / 24h / 当天提醒；seed 的"今天"是 **2026-09-16**。所有日期显示 mm/dd/yyyy。

## 一期覆盖的需求（对照客户文档）

- **Case 类型**：托运（全包 / 仅订舱）、随机、仅代办文件；可中途改类型，已完成步骤保留，其余按新流程重建并留日志。
- **13 套文件 workflow 模板**（`src/data/workflows.ts`）：出发地中国 4 套、北美 9 套，按猫 / 狗区分；收尾流程按类型拼接（全包：送机 → 清关 → 收尾款 → 境内转运 → 到家；仅订舱：收尾款 → 送机 → 自行清关 → 到家；随机：提醒值机 → 到家；仅代办：文件转交主人）。收尾款节点可调（清关后 / 送机前 / 到家后）。
- **附件**：Timeline 每一步带附件要求的，必须先上传才能点「标记完成」；Case 级「其他文件」；航班分区「航司文件」。附件在会话内可下载。
- **航班与订舱**：只有订舱能改航班；操作部只能填「航变情况」（本单时间暂定 / 客人要求提前 / 延后 / 本单取消）。改航班旧记录保留，只变颜色（已替代 / 已取消）。订舱确认后预计出发日期变实际出发日期并回写销售接单。前期文件办完自动转给订舱，也可「提前通知订舱」。
- **随机**：是否需要随机人（与列表分区联动）、随机状态、随机人、客舱 / 氧舱、进度备注、异常。
- **今日总控**：近 7 天（即将出发 / 接送 / 需收款 / 即将到达 / 需寄护照）+ 近 3 周（本周 / 下周 / 下下周出发 / 需约医院 / 需安排接送），桶按角色配置。
- **待办**：按周分区、按时间排序、可筛负责人；司机类任务状态跟司机端联动；后段待办有落地日期（local）、入境口岸、「已到家」按钮；财务待办 = 需收款。
- **Case 列表**：托运 / 随机两张，搜宠物名 / File No / 芯片号；随机分「需要随机人 / 不需要随机人」。
- **紧急变动**：航变、司机任务变动、司机异常 / 无法确认、随机异常全部汇总；相关人「我已确认」需二次弹窗；按出发时间排序；到家后才消失。管理员可看短信发送记录。
- **短信（Twilio）**：只在紧急事件时发给管理员 + Case 负责人 + 接单销售（司机、财务不发）。未配置时为模拟发送并记录。
- **司机端**：任务类型（接回寄养 / 接去医院送回 / 接去医院送寄养 / 仅接送 / 送机 / 接机 / CFIA 盖章）、司机确认 / 无法确认 + 原因、已出发 / 已接到 / 已完成、异常 + 原因列表；操作部修改任务后司机需点「我已看到」；地址点导航、电话点拨打；历史任务。
- **销售接单表**：6 个必填项 + 宠物名后补；操作部录单后 File No 自动关联、订舱确认后实际出发日期自动回填；按实际出发月份分组并计数；操作部可从接单直接「录单」。
- **收款情况（不记账）**：订单金额 / 定金 / 尾款 / 币种来自接单；操作部只能改尾款状态、加额外费用（公司承担 / 客人承担 / 暂未确认，不可删除）；客人承担的费用自动进财务「需收款」。
- **备注与日志**：内部备注不可删除、标注添加人；所有改动自动进操作日志。
- **自动归档**：所有航班已确认且已到家 → 自动归档；订舱侧到达后保留 1 个月。
- **日历**：实际出发日 / 预计出发日颜色区分；随机四色（文件已定 / 未定 × 随机人已定 / 未定）；司机只看自己（日 / 周）；财务只看已确认的。
- **账号与权限**：8 角色 × 9 分区 × 看 / 改 矩阵，点击即生效。

## 演示路径（已用 headless Chrome 跑通）

1. **Teddy（托运订舱）→ 我的待办 → 旺财** → ⑤ 标记航变 → 无仓位 → 确认：旧航班变「已替代」、影响清单、紧急变动 + 短信（模拟）通知 Rita / 小林 / 小张 / Amy。
2. **Rita → 紧急变动**：点「我已确认」→ 两次确认 → 记录确认人；底部看短信发送记录。
3. **老王（司机）**：今日任务里「司机确认」；Luna 的任务变动点「我已看到」；点「异常」选原因提交 → Rita / 小林 / Amy 收到紧急变动 + 短信。
4. **小林 → Luna**：④ 健康证步骤「标记完成」是禁用的，上传文件后才能点；完成后健康证签发日自动写入、进日志。
5. **Amy → 新单录入** 保存 → 切到 小林 → 接单信息表 → 该行「录单」→ 创建并打开：Case 关联接单，定金 / 尾款带入，接单表回填 File No。
6. **Rita → 汤圆（仅代办文件）**：③ 路线里把 Case 类型改成「托运」→ 自动补上订舱 / 送机 / 清关 / 收尾款，已完成步骤保留，日志留痕。
7. **小张（后段）→ 我的待办**：Peanut 点「已到家」→ 自动归档、该 Case 的紧急变动消失。
8. **Vivian → Lucky**：随机状态改「已添加宠物位置」→ 随机订舱步骤完成、出发日期变实际。
9. **权限**：Vivian 打不开托运 Case，小林打不开小周的 Case。

## 代码结构

```
src/
  app/
    page.tsx                  登录选择页（8 角色）
    api/sms/route.ts          Twilio 发送（未配置则 mocked）
    (dashboard)/
      layout.tsx              应用外壳 + 路由权限守卫（司机为手机框 + 底部导航）
      dashboard/ todo/ cases/ accompany/ calendar/ alerts/ routes/ archive/ sales/ history/ permissions/
      cases/[id]              Case 详情
  components/
    shell/                    Sidebar、Topbar（含手机底部导航）、UserSwitcher、DateControl、NotificationBell
    case/                     CaseDetail、WorkflowProgress、AttachmentList、各弹窗（录单 / 创建 / 修改任务 / 订舱 / 航变 / 操作侧航变 / 随机异常）
    case/sections/            ①～⑨ 分区
    dashboard/                CaseTable（总控桶）、CaseList（列表）、FlightTable、Filters、BucketSection
    tasks/DriverTaskCard.tsx  司机手机端任务卡（确认 / 无法确认 / 异常 / 变动确认）
  data/
    options.ts  roles.ts  users.ts  workflows.ts（13 套模板）  routes.ts  cases.ts  tasks.ts  sales.ts  alerts.ts  extras.ts（附件 / 备注 / 费用 / 通知 / 日志）
  lib/
    workflow.ts               模板 + 收尾拼接、倒推 Timeline、改期重排、改类型重建、阶段推导
    permissions.ts            页面 / 分区权限、Case 可见范围（按角色 / 入境地区）、通知与短信对象
    buckets.ts                今日总控 7 天 / 3 周桶、颜色表
    sms.ts  reminders.ts  impact.ts  dates.ts（mm/dd/yyyy、按周）
  store/useAppStore.ts        zustand 单 store：所有业务动作（录单、附件、步骤完成校验、航变、司机状态、紧急变动 + 短信、销售单、自动归档）
```
